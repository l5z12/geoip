    03. JSON API

    Use GET with a public address, or omit ip to look up the caller. No API key required.

    IPv4

    GET /api/lookup?ip=1.1.1.1

    IPv6

    GET /api/lookup?ip=2606%3A4700%3A4700%3A%3A1111

    Caller address / database status

    GET /api/lookup
GET /api/status

    Any location or network field may be unavailable. The records object contains complete, unfiltered Country, City and ASN matches, or null where no record is available. Matched network values identify database address ranges. Errors return an error object with a code and message.

    04. About the result

    IP geolocation is approximate, not a person’s exact physical location or street address. VPNs, proxies, mobile networks and database age can affect the result. An ASN identifies an autonomous system, not an individual.

    City names, postal codes and coordinates are estimates when available. Coordinates represent an approximate area; the accuracy radius is in kilometers, not a guarantee of precision. Missing values do not imply a negative answer. Availability of fields and traits depends on the matched GeoLite2 records.

    This product includes GeoLite2 data created by MaxMind. Country, City and ASN databases are downloaded directly from MaxMind and checked daily for updates.
